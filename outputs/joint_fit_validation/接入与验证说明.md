# 联合无分箱点估计接入与验证

已将用户提供的 `analyze_real_spdc_1_mult.m`（V4）计算内核改编为平台的独立分析分支。
原文件未改写；未向 GitHub 上传或推送。

## 使用

运行 `launchCoincidenceSimulator`，在左侧“联合无分箱”页选择“启用”，再运行新仿真、
导入 Start/Stop TXT/BIN 或点击“按当前设置重新计算”。主报告模型默认非对称双高斯，
同时保留单高斯结果。新功能默认关闭，旧参数兼容。

- “最窄有效窗口”策略有有效推荐时，使用其真实左右边界；“仅推荐”也生效。
- 推荐无效、手动模式或其他选择策略，使用算法设置中的实际窗口。
- nσ、n bin、n FWHM 的窗口按设置解析；n bin 的右开区间保持一致。
- 不将该窗口移到双高斯中心，也不沿用原脚本固定的 3.57 ns 参考窗。
- 全谱拟合使用时间谱搜索范围，窗口用于原始、偶然、净计数及模型捕获率。

结果位于中央“联合无分箱拟合”页、右侧点估计指标组及 `out.jointFit`。
完整相关峰面积与窗内净计数分别报告，净计数不作非负截断。
本分支无 Bootstrap、拟合 Bootstrap 或 Hessian 置信区间。原统计页仍独立控制原窗口
结果；若不需要其 Bootstrap，也应在“统计不确定度”页选择关闭。

勾选“符合结果与参数列表 CSV”后会附带 `*_joint_fit_summary.csv` 和
`*_joint_fit_profile.csv`；批量、逐秒独立批处理及种子扫描均使用相同接入。
拟合不可用时仍导出状态汇总。曲线包含实际 bin 左右边界，单位为秒。

## 验证结果

- 全套 **102/102** 项 MATLAB 测试通过，包括新增 12 项联合拟合测试。
- 新增及相关核心文件 MATLAB 静态检查均为零问题。
- 实际 GUI 回调验证：仅推荐模式采用 1.1 ns 最窄窗；切换到算法设置的 n bin 窗后，
  使用 0.7 ns 实际窗；关闭新分析后清空对应结果和图形。
- 验证了真值不参与拟合、全局随机状态不变、all-pairs 重复事件保留、范围末端
  非完整 bin 的积分、参数兼容、空/稀疏数据、结果导出、逐秒批处理及种子扫描。
- 与原脚本使用同一批时间戳和拟合设置对照，单高斯峰面积差约 1.16e-5 对，
  双高斯峰面积差约 -9.88e-7 对。详细数值见 `original_script_comparison.csv`。

最终验证日志：`validation.log`。界面截图：`joint_fit_adaptive.png`、
`joint_fit_algorithm_window.png`。两种选窗结果的 CSV 和实际参数 MAT 同目录保存。

## 范围与限制

新拟合独立枚举 all-pairs，始终保持 tB-tA 的方向。完整面积的仿真评价目标为
共有不同非零 pairID 数 Nrec；窗内净计数以同一窗口下的真实对数为目标。
不将完整面积当作光源产生对数、逐事件匹配结果或探测器 PDE。

保留原算法的奇偶块交叉拟合诊断，主估计仍来自全数据。时间块不足四个时交叉拟合
可用性会明确记录，不阻止全数据点估计。临时 lag 文件在正常结束或异常时清理。
该接入与平台原窗口分析并行，原匹配数组的内存开销仍然存在。
