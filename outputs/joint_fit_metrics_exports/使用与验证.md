# 联合拟合指标与导出

## 指标展示

启用“联合无分箱”并运行或重新计算后，右侧顶部展示联合拟合特有指标：
完整相关峰面积、模型对照、拟合背景、捕获修正面积、核心/尾部形状、整体 IRF
均值与标准差、交叉拟合诊断和完整面积误差。

原指标组已有的计数/速率、窗口、峰位置/FWHM、TP/FP/Nrec 和窗内误差不在联合组
重复展示。数值型 `out.jointFit.summary` 和导出文件仍保留全部指标。
拟合不可用或实测没有真值时显示 N/A，不将初始响应参数当作拟合结果。
本次未增加 Bootstrap 或拟合 Bootstrap。

## 导出

单次导出、文件夹批处理及随机种子扫描均新增独立选项：
“联合无分箱拟合汇总、曲线与完整结果（CSV/MAT）”。无需同时勾选普通结果。

| 文件 | 内容 |
| --- | --- |
| `*_joint_fit_summary.csv` | 两个模型的完整指标、计数率、形状、选窗、收敛诊断、真值误差 |
| `*_joint_fit_profile.csv` | 时间差、实际 bin 边界、观测计数、两种模型曲线及所选模型残差 |
| `*_joint_fit_result.mat` | 完整 jointFit、实际 params、dataMode |

拟合不可用时仍输出汇总和 MAT；无曲线时不生成曲线 CSV。
同时选择普通结果与联合拟合不会重复导出。明确取消联合选项时不生成独立联合文件，
普通结果 CSV 仍保留完整数值指标。旧命令行调用未提供新选项时保持此前附带两个
联合 CSV 的兼容行为。逐秒和固定分窗导出也支持完整联合结果。
