054 4.2  候选集合与筛选
055 仅当 selection == "bootstrap-bagging" 时，用自动最小全窗 Wmin = 2√2·sigma·erfinv(targetCapture) 构造细网格；按 p.tdc.resolution 向上取整并去重。保留用户当前 windowCandidates，与细网格取并集。
056 候选有效性完全复用现有 valid / backgroundZ / 旁窗完整性 / 捕获率检查；禁止借助 TP、FP、pairID、isTrue 或已知仿真真值筛选。
057 从有效且 W <= 1.40×最小有效 W 的集合建立 Bagging 候选池。必须包含最窄有效窗口；其余候选从解析评分较优者与宽度均匀分布的候选中组合，去重并按窗口升序；总数不超过 maxPool。
058 若限定 1.40×范围内有效候选为空，但全局存在其他有效候选，则扩大到所有有效候选形成池并记录 RangeFallback=true，不得静默返回无效窗口。
059 4.3  每个候选只建块一次
060 对池中的每个候选 Wj，复用 optimizeCoincidenceWindow.m 已有 provisional 构造路径，调用 buildBootstrapBlocks(provisional) 一次，缓存：
061 X(:,j) = blocks.C(:) - blocks.side(:);  % 同一块里的净符合capt(j) = capture(index_j);            % 模型捕获率W(j)    = widths(index_j);             % 有效物理窗口（s）
063 所有候选必须来自同一批训练块，块数 M 和块边界一致。对于不完整旁窗或 NaN 净符合块，按现有 valid 规则剔除该候选。不得在每次 Bagging 重抽样中重新执行 all-pairs、峰形拟合、bin 选择或背景窗重新匹配。
064 4.4  重复选窗与聚合
065 在当前训练块上重复 K=101 次有放回抽样。每次抽取 M 个块索引，各候选必须共用同一组索引。对每个候选计算对应的 Bootstrap 方差评分。
066 stream = RandStream('mt19937ar', 'Seed', ...    mod(double(p.uncertainty.seed)+99173, 2^32));for b = 1:101    I = randi(stream, M, M, 1);    % 所有 W 复用同一 I    XB = X(I,:);    % 区块可交换重抽样下：总净符合的 Bootstrap 方差    ub2 = M * var(XB, 1, 1);      % 1×候选数，使用总体方差    J   = ub2 ./ (capt(:)'.^2);    [~, w] = min(J);              % 同分优先取更小 W    chosen(b) = W(w);endWmean = mean(chosen);% 投影到“所有通过硬约束”的细网格，保证最终 W 合法[~,kk] = min(abs(widths(valid) - Wmean));validIdx = find(valid);choice = validIdx(kk);
068 重要：M×var(blockNet,1) 是在等长、非重叠块 i.i.d. 重抽样定义下，整段净符合和的条件 Bootstrap 方差；它等价于无限内层重抽样的方差，不必为 101 次外层抽样重复运行 2000 次 runBlockBootstrap。若后续改变块抽样规则，应重新核对这个公式。

087 5.3  失败与边界处理
088 uncertainty.enabled 为 false：Bagging 模式不执行；返回状态 bagging-requires-bootstrap，并保留明确诊断，不静默转成其他策略。
089 候选数为 0：沿用 no-valid-window；候选数为 1：直接选唯一有效候选，Bagging 频率为 1，状态 bagging-single-candidate。
090 块数 < p.uncertainty.minBlocks：返回 insufficient-bagging-blocks，并提示使用现有分块控件调整块长；不额外创建 UI。
091 抽样方差非有限、含缺失值、候选完全无法评估：返回 bagging-score-unavailable；不得将 NaN 当 0 或无提示回退。
092 如果最终投影窗口未在 Bagging 候选池中，仍必须重新计算该窗口的正式 Bootstrap u 与 CI，避免输出空的不确定度。
093 随机性：只用局部 RandStream；相同输入与 seed 必须逐位或在浮点容差内复现同一选窗。
